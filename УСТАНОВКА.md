# Установка Revit AI Render 0.3.1

На Windows нужны Revit 2024 или 2025, клиент OpenSSH и настроенный SSH-доступ к Mac. На Mac нужны запущенный Siliconed, установленная Qwen-Image-2.1-Turbo и доступная команда `silicontrol`. ZeroTier подходит для соединения между компьютерами. Для режима «Маска» также нужны MFLUX с поддержкой Qwen-Image-2.1-Turbo и локальный совместимый чекпойнт.

## Первый запуск

Распакуйте архив и откройте PowerShell в каталоге `distribution`.

```powershell
.\Install-RevitAiRender020.ps1 -RevitYear 2024
```

Откройте новый сеанс Revit. В штатном диалоге при необходимости проверьте путь к DLL и подтвердите её загрузку. На вкладке **AI Render**, в панели **Визуализация**, нажмите **Подключение**. Укажите SSH-псевдоним или `пользователь@адрес`. Оставьте предложенный путь к `silicontrol` или укажите свой абсолютный путь на Mac. Нажмите **Проверить связь**, затем **Сохранить**.

Установщик поддерживает Revit 2024 и 2025. При необходимости начальные параметры можно передать через `-SshTarget` и `-SilicontrolPath`. При наличии настроек 0.1 установщик может взять из них SSH-псевдоним и путь к CLI. Надстройка использует существующую аутентификацию Windows OpenSSH.

Для правки по маске раскройте **MFLUX для правки по маске** в окне подключения. Укажите абсолютные пути на Mac к Python из окружения MFLUX, команде `mflux-generate-qwen-2.1-edit` и каталогу чекпойнта. Те же значения можно передать установщику в `-MfluxPython`, `-MfluxCli` и `-MfluxModel` вместе с `-SshTarget`. Настройки хранятся на Windows в `%LOCALAPPDATA%\RevitAiRender020\settings.json`. Использование весов регулируется условиями их распространителей. [Документация Siliconed](https://github.com/gwenn-ha-dev/Siliconed/blob/main/docs/REMOTE-CONTROL.md) · [Карточка чекпойнта MFLUX Q4](https://huggingface.co/mflux-community/qwen-image-2-1-turbo-mflux-q4) · [Условия использования модели Qwen](https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo/blob/d65dbc9a7e8f6b5479e33dee6030eaab2a906509/LICENSE)

## Обновление существующей версии

```powershell
.\Install-RevitAiRender020.ps1 -RevitYear 2024 -Update
```

Установщик создаёт отдельный каталог для DLL, обновляет регистрацию и выводит путь к резервной копии предыдущего манифеста. Существующие настройки используются повторно. Новый сеанс Revit загрузит обновление. Для отката закройте Revit и восстановите манифест из резервной копии.

Для работы из Codex добавьте при установке `-EnableMcp`. [Подключение MCP](MCP.md)

## Использование

1. Нажмите **Новый рендер**, выберите сохранённый 3D-вид и дождитесь предпросмотра.
2. Для локальной обработки включите **Правка по маске** и выделите участок кистью или прямоугольником. Ластик убирает часть выделения. Увеличенный кадр перемещается правой кнопкой мыши.
3. Введите промпт и нажмите **Генерировать**. Флажок «Сохранять геометрию» добавляет просьбу в промпт. Детали на рендере могут отличаться от BIM-модели.
4. Готовый рендер откроется в панели и отдельном окне. Кнопка **Сохранить PNG** создаёт копию. Флажок **Сравнить с исходником** включает ползунок.
5. Предыдущие результаты и параметры доступны в **Истории**. После разрыва связи используйте **Проверить задачу**.

Задачи Windows хранятся в `%LOCALAPPDATA%\RevitAiRender020\jobs`. На Mac надстройка использует отдельные каталоги внутри `~/.revit-ai-render/jobs` и `~/.revit-ai-render-v020/jobs`.

## Сборка

Установите .NET 8 SDK и нужные версии Revit. Соберите обе цели с помощью команды ниже. Для сборки только одной DLL добавьте `-f net48` или `-f net8.0-windows`. По умолчанию проект ищет Revit в стандартном каталоге установки. Другой каталог для выбранной цели можно передать через `-p:RevitDirectory`.

```powershell
dotnet build .\src\RevitAiRender.csproj -c Release
```

Для запуска установщика с собственной сборкой поместите `RevitAiRender020.dll` из `src/bin/Release/net48` в `distribution/2024` или из `src/bin/Release/net8.0-windows` в `distribution/2025`.
