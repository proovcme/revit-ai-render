# AI Render в Codex

MCP связывает Codex и работающую надстройку AI Render 0.3 на том же компьютере Windows. Откройте нужный проект Revit. Генератор и его очередь работают на Mac через существующий SSH/SFTP.

## Подключение

В PowerShell из каталога `distribution` выполните установку с параметром `-EnableMcp`. Для обновления существующей установки используйте также `-Update`.

```powershell
.\Install-RevitAiRender020.ps1 -RevitYear 2024 -Update -EnableMcp
```

При первой установке вместо `-Update` задайте `-SshTarget 'render-mac'`. Установщик выведет путь к `RevitAiRender.Mcp.exe`. Для запуска этого файла нужен .NET 8 Runtime x64.

```powershell
codex mcp add revit-ai-render -- 'C:\путь\из\установщика\RevitAiRender.Mcp.exe'
```

Запустите новый сеанс Revit и откройте новый чат Codex. Если одновременно открыто несколько сеансов Revit с включённым AI Render MCP, передайте в настройках сервера `--revit-pid <PID>`. Идентификатор можно посмотреть в диспетчере задач или в сообщении MCP о нескольких доступных сеансах.

## Команды

| Команда | Что возвращает |
|---|---|
| `render_views` | Название и токен активного проекта, ID 3D-видов. Для больших списков используйте `nextOffset`. |
| `start_render` | Запускает полный кадр через Siliconed с указанным промптом и возвращает ID. Использует название, токен проекта и ID вида из `render_views`. |
| `render_status` | Состояние задачи и прогресс, если его сообщает Siliconed. |
| `list_renders` | Готовые рендеры из истории, включая маски. Поддерживает фильтр по названию проекта и постраничный вывод. |
| `get_render` | Возвращает итоговый PNG в чат. С `original=true` возвращает исходник. |

При первом запуске задайте новый UUID как `requestId`. Если связь оборвётся, проверьте `render_status` с этим ID. Повтор того же запроса с тем же UUID не отправляет второй кадр. Для задачи с другим промптом нужен новый UUID. Если связь с Mac прервалась и статус показывает, что наблюдение можно возобновить, используйте **Проверить задачу** в истории Revit.

MCP запускает редактирование полного кадра. Маска рисуется и запускается через панель Revit. Отмена текущей задачи доступна в панели. Готовый результат открывается в Revit целиком. По запросу MCP возвращает тот же PNG в чат, до 8 МиБ на изображение.

MCP использует стандартный ввод и вывод, а соединение с Revit проходит через именованный канал Windows, доступный текущей учётной записи. В Revit канал включается при старте, пока существует `%LOCALAPPDATA%\RevitAiRender020\mcp.enabled`. Чтобы отключить его, после закрытия Revit уберите этот флаг и запись `revit-ai-render` в Codex.

## Сборка сервера MCP

```powershell
dotnet publish .\mcp\RevitAiRender.Mcp.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Поместите `RevitAiRender.Mcp.exe` в `distribution/mcp` для установки вместе с надстройкой. Сервер использует официальный C# SDK MCP. [SDK](https://github.com/modelcontextprotocol/csharp-sdk) · [Лицензии зависимостей](licenses/README.md)
