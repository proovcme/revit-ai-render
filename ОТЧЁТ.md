# Проверки версии 0.3.1

- Сборки для Revit 2024 и 2025 и локальный сервер MCP собраны без ошибок.
- Вне Revit на .NET Framework 4.8 и .NET 8 проверены переключение полного кадра и маски, инструменты маски, просмотр результата, сравнение и загрузка полей окна подключения. В тестовом каталоге проверено сохранение настроек, в том числе уже существовавших полей.
- С обеих версий .NET выполнен запрос к работающему Siliconed на Mac и проверена доступность настроенных путей MFLUX. Контрольная сумма локальных настроек совпала до и после проверки.
- В тестовых каталогах под Windows PowerShell 5.1 проверены чистая регистрация надстройки, обновление с 0.3.0, резервная копия манифеста и сохранение настроек.
- В Revit 2024.1.10 загружена опубликованная 0.3.1. На ленте видны «Новый рендер», «Результат», «История» и «Подключение». В окне подключения проверены доступность SSH, ответ Siliconed и пути MFLUX.
- Прямой MCP-клиент через опубликованный сервер 0.3.1 вызвал `render_views`, `start_render`, `render_status` и `get_render` в настоящем Revit 2024.1.10. Перспектива переговорной прошла экспорт, обработку в Siliconed, скачивание и автоматическое открытие в Revit. Получен PNG 1280 × 800, SHA-256 `8384ff026899a4523b163dd31bfef89d3d0ce1868abe5e422298cd257419b9b9`. Повтор запроса с тем же UUID вернул ту же задачу.
- Отдельный сеанс Codex получил статус и PNG той же задачи через MCP. В сеансе без подтверждений Codex отклонил `start_render` до приёма запроса. Запуск непосредственно из Codex с подтверждением пока не проверен.

# Проверки версии 0.4.0

- Два последовательных экспорта одной перспективы из Revit 2024 при ширине 1920 пикселей совпали попиксельно. Проверка ручной маски отклоняет изменённый пиксель или размер кадра до передачи на Mac.
- Код построения масок проверен в Revit 2024 на копии проекта. Из идентификаторов стола и экрана получены маски видимых частей. Полностью скрытый в этом ракурсе элемент отклонён. Служебный вид откатился, число 3D-видов и флаг изменений у копии сохранились. Контрольная сумма исходного RVT совпала до и после проверок.
- С новым сервером MCP и кадрами, полученными в Revit, проверена обработка экрана через MFLUX на Mac. В тесте Revit-экспорты были переданы в испытательный канал. Рабочий кадр MFLUX 736 × 640, итоговый PNG 1920 × 1213. Внутри маски изменились 144 458 пикселей, снаружи 0. PNG из MCP совпал с локальным файлом по SHA-256.
- Собраны обе версии надстройки и сервер MCP. Новые элементы панели проверены вне Revit.
- В изолированных каталогах Windows PowerShell 5.1 проверены отложенное обновление, сохранение пути и ID существующей регистрации, отказ при её изменении во время ожидания и резервная копия DLL. Ожидание Revit проверялось на имитации работающего процесса.
- Установщик применил 0.4.0 после полного выхода из Revit 2024. Путь к DLL и манифест сохранены, резервная копия 0.3.1 проверена. При первом быстром переоткрытии установщик продолжил ожидание, следующий запуск выполнили после завершения обновления. Версия 0.4.0 проверена в работающем процессе Revit.
- Сквозной тест установленной 0.4.0 в Revit 2024.1.10 прошёл через физический Mac. MCP передал ID настенного экрана переговорной. Revit построил маску по элементу, MFLUX обработал участок 736 × 640, через `get_render` получен PNG 1920 × 1213. На панели Revit открылась вкладка «Результат». Внутри маски изменились 144 652 пикселя, за её пределами 0. SHA-256 результата `111eb7dea74e657a678f34a59cdbc8cdec7e0c0ac17dca6f7922dd192bb36038`. Контрольная сумма RVT и число 3D-видов совпали до и после теста.
- Дополнительный сквозной тест с настроенным сервером MCP 0.4.0 прошёл через Codex CLI. Вызов `start_render` передал ID настенного экрана `214445`, а `get_render` вернул PNG 1920 × 1213 после обработки в MFLUX. Полученный PNG побайтово совпал с сохранённым результатом. За пределами маски изменилось 0 пикселей. SHA-256 результата `6464a5993b5aad12e2a9064a6192c998152fac661c018f4653b3151834eca349`.

# Проверки версии 0.3.0

- Сборки Revit 2024 и 2025 и отдельный сервер MCP x64 собраны без ошибок и предупреждений. Повторно проверены маска, сравнение и конфигурация MFLUX на .NET Framework 4.8 и .NET 8.
- На обоих стендах клиента MCP подключили по stdio к именованному каналу надстройки. Проверены пять команд, возвращение источника и результата как PNG с той же SHA-256, ошибки при неверном ID, фильтрация истории и защита от повторного запуска по тому же UUID.
- 0.3.0 установлена для Revit 2024. Сохранена резервная копия прежнего манифеста. Запись MCP добавлена в Codex.
- Сквозной тест новой задачи через MCP в Revit ожидает загрузки DLL в испытательном сеансе.

# Проверки версии 0.2.1

- В Revit 2024.1 проверены загрузка надстройки, лента AI Render, узкая закрепляемая панель, открытие сохранённого результата, крупный просмотр и сравнение. При перестановке ползунка граница кадров совпала с видимым разделителем.
- Полный сквозной тест на испытательной копии проекта прошёл через Siliconed. Revit экспортировал 3D-вид, отобразил прогресс и автоматически открыл готовый PNG 1184 × 864 после его возврата с Mac. Контрольная сумма файла RVT совпала до и после теста.
- Проверка локального редактирования в предыдущем выпуске подтвердила совпадение всех пикселей за пределами маски. В 0.2.1 проверено открытие этого рендера в интерфейсе.
- Публичный пакет собран для Revit 2024 и 2025. В публичной сборке пути к инструментам и весам MFLUX задаются пользователем. Сборка, проверка WPF и установка с тестовыми параметрами проверены отдельно. Публичную DLL после замены настроек отдельно в Revit не запускали. Revit 2025 в испытаниях интерфейса не участвовал.
